# AR visuals for the solution deck

These are **image-edit prompts** for the building owner's notice. In ChatGPT, attach the original inspector photo (`assets/original.jpg`), paste one prompt per image, and save the results as `assets/s1.png` … `assets/s5.png` (same orientation as the original). Or use the panel to the right of the phone: Copy prompt, then drop or paste the result.

Every result must look like the *same photograph* (same street, hedge, pole, wires, house, light) with the described change made to the plants, plus a light augmented-reality highlight of what changed. Nothing else: no panels, no boxes, no text blocks, no code numbers. Each callout states the one measurement the owner has to meet.

Shared style block — paste this after each prompt:

> Output the image at exactly the same size and aspect ratio as the attached photo: portrait, 820 × 1474 pixels (9:16), full frame. Do not crop, extend, rotate, zoom or reframe it; every element must stay in the same place. Keep the photo photorealistic and unchanged except for the described edit. Show the change with a soft glowing cyan outline around the area that was cut or removed and a faint translucent cyan ghost of the plants that are gone. Add at most two short plain-English callouts in a clean sans-serif, each a few words with the exact measurement (for example “Trim branches up to 10 ft”), attached with a thin cyan line to the spot they describe, with a small cyan ruler tick showing that height or distance. No panels, no side boxes, no bullet lists, no formulas, no code references, no logos, no people. Calm, precise, like a field tool from 2030.
